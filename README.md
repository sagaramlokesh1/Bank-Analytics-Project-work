# 🏦 Bank Analytics Project

## 📌 Project Overview
The Bank Analytics Project focuses on analyzing banking data to understand
customer behavior, financial performance, and key banking trends.

The project uses Excel and SQL for data preparation and analysis, while
Power BI and Tableau are used to create interactive dashboards and
visualize key performance indicators (KPIs).

## 🎯 Project Objectives
- Clean and prepare banking data for analysis
- Analyze customer and financial trends
- Identify important banking KPIs
- Perform SQL-based data analysis
- Build interactive dashboards
- Present insights for data-driven decision-making

## 🛠️ Tools & Technologies
